# Гранд-Офис

Витрина офисной мебели, оформление заказов, комплектация офисов и управление поставками.

## GitHub Pages

Сайт публикуется из `main`. Прайс и карточки выгружены из открытой части действующего каталога. На GitHub Pages форма готовит письмо с запросом поставки, доставки или сметы. Покупатель отправляет его из своей почты.

После обновления выгрузки запустите `python3 scripts/prepare_catalog.py`, затем `python3 scripts/prepare_catalog_facts.py`. Первая команда обновит компактный индекс и данные каталога, вторая — сведёт размеры к миллиметрам, отметит комплектующие и обновит проверяемые варианты отделки.

Полную структуру разделов можно обновить флагом `--categories`. Передайте папку со страницами публичного API `/wp-json/wp/v2/product_cat`, содержащими поля `id,name,slug,parent,link`. Файл `data/indexing.json` сохраняет список видимых в каталоге товаров, для которых в действующей карте сайта нет адреса. Они доступны в каталоге, а после запуска поисковая карта перечисляет адреса уже опубликованных товаров.

## Запуск с админкой

Нужен Python 3.11 или новее. Задайте `GRAND_ADMIN_PASSWORD` через настройки среды и запустите `python3 server/main.py`. Сайт доступен на `http://127.0.0.1:8080`, управление на `/office/`. По умолчанию логин `office`. Имя администратора можно изменить через `GRAND_ADMIN_USER`. Пароль должен содержать не менее 16 символов. Без него админка закрыта.

`GRAND_DB` задаёт путь к файлу SQLite. На сервере храните базу и её резервные копии на постоянном диске вне статической папки. Для внешнего доступа используйте HTTPS и прокси с ограничением частоты запросов. Сервер слушает только loopback по умолчанию. Путь к оригинальной политике конфиденциальности следует проверить при выпуске на новом домене.

В админке доступны заявки, заказы и статусы, редактирование цены и остатка, привязка внешних предложений, предварительный просмотр и журнал импортов. Форматы загрузки — XML «Экспро» и CSV с колонками `offer_id,price,stock`. Ссылку для XML задаёт `GRAND_EXPRO_URL`. После сверки настроек ежедневный запуск можно задать планировщиком командой `python3 server/main.py --import-expro`. `GRAND_STOCK_TTL_HOURS` определяет, как долго показывается подтверждённый остаток.

Подключение договорных API заводов, CRM и аналитики выполняется после выдачи доступов и выбора серверного размещения.

## Серверный выпуск

Сервер отдаёт товары по исходным URL `/product/<slug>/`, категории по полным путям `/product-category/…/`. HTML содержит название, описание, разделы и ссылки ещё до загрузки JavaScript. Алиасы переводят на соответствующий адрес с HTTP 301. Корзина, оформление, результаты поиска и выдача с фильтрами закрыты от индексации. На серверном выпуске безопасно проверить это с пустой тестовой базой до подключения домена.

В `deploy/` есть образец службы systemd, файла окружения и фрагмент конфигурации Nginx. Служба рассчитана на системного пользователя `grand-office` и Python 3.11+. Файл окружения хранится отдельно от репозитория. Для серверного предпросмотра оставьте `GRAND_INDEXABLE=0`, настройте секрет администратора и проверьте поступление заявки с файлом, открытие её в `/office/` и сохранение после перезапуска.

Для переключения `grand-office59.ru` нужен отдельный HTTPS-адрес действующего WordPress, доступный после смены DNS. Укажите его в `GRAND_LEGACY_ORIGIN` и в правиле Nginx. Через него остаются доступны загруженные фотографии, вариантные данные WooCommerce, политика конфиденциальности и прежние страницы, которых пока нет в новой витрине. Проверьте реальные адреса и политику обработки данных в рамках нового размещения до включения приёма реальных заявок.

На подтверждённом рабочем домене задайте `GRAND_PUBLIC_ORIGIN` и `GRAND_INDEXABLE=1`, затем отправьте `/sitemap.xml` в панели поисковых систем. Для отката верните маршрутизацию на прежний сайт и сохраните серверную базу с заявками, принятыми новой версией.
