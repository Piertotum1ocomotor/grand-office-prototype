# Гранд-Офис

Кликабельный прототип сайта офисной мебели для GitHub Pages.

- Каталог и поиск, три примера товарных карточек, переключение вариантов и демо-корзина.
- Комплектация на 1, 4 или 8 рабочих мест и пример подтверждения заявки.
- Цена, наличие и результаты оформления демонстрационные. Корзина существует в памяти текущей страницы. Отправки данных нет.
- Логотип, шрифт и фотографии взяты с публичного сайта [Гранд-Офис](https://grand-office59.ru/).

Запуск без сборки. Откройте `index.html` или раздайте файлы любым статическим сервером.
